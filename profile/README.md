# email-utils

Small, fast, well-tested building blocks for working with email addresses in JavaScript and TypeScript.

| Package                                                                            | Answers                                      |
| ---------------------------------------------------------------------------------- | -------------------------------------------- |
| [`@email-utils/validator-syntax`](https://github.com/email-utils/validator-syntax) | Is it well-formed?                           |
| [`@email-utils/classifier`](https://github.com/email-utils/classifier)             | What is it? Provider, disposable, role, typo |
| [`@email-utils/sanitizer`](https://github.com/email-utils/sanitizer)               | What's its canonical form?                   |
| [`@email-utils/validator-dns`](https://github.com/email-utils/validator-dns)       | Can the domain receive mail?                 |
